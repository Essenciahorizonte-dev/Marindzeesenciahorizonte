# Website Marindze Consultoria & Serviços, E.I.

Website institucional estático (HTML5, CSS3 e JavaScript puro), compatível com qualquer hospedagem convencional.

## Estrutura
- `index.html` — página inicial; `pages/` — restantes páginas
- `css/` — `style.css` (base), `animations.css` (logótipo e entradas), `responsive.css`
- `js/` — `main.js` (animação do logótipo), `navigation.js` (menu móvel)
- `assets/logo/` — logótipo com fundo transparente

## Cores da marca (medidas no logótipo)
Azul `#042C54` · Laranja `#FC6C04` · Branco `#FFFFFF` · Cinza `#E9EEF4`
